```mermaid
flowchart LR
    A[Reconnaissance] --> B[Attack Surface Discovery]
```

| :-- | :-- |
| **Reconnaissance** | Understand the target and identify exposed assets. |
| **Discovery & enumeration** | Map functionality, endpoints, services, and inputs. |
| **Testing & validation** | Combine automated scanning with targeted manual testing. |
| **Risk assessment** | Evaluate impact and prioritize findings. |
| **Reporting** | Document evidence and provide clear remediation guidance. |
